Excel Sales Dashboard (Power Query Project)

🔹 Project Overview

This project demonstrates how to build a professional, interactive Excel dashboard using Power Query, Pivot Tables, and Slicers.
The dashboard helps analyze sales performance, bonuses, and employee activity across departments and months.

🔹 Tools & Technologies Used

Microsoft Excel

Power Query (ETL & Data Transformation)

Pivot Tables

Slicers & Pivot Charts

KPI Cards (GETPIVOTDATA)

🔹 Key Features

Cleaned and transformed raw data using Power Query

Merged multiple tables (Employee Info, Sales Data, Targets)

Grouped data by Department and Month

Built interactive KPIs:

Total Sales

Total Employees

Total Bonus

Dynamic filtering using slicers (Month & Department)

Business-ready dashboard layout
